# J8 语言完整语法参考

本文档是 J8（Jadeight 8，C 系语法的 Jadeight 字节码语言）的**形式文法规范**，
与 `src/lexer.cpp`、`src/parser.cpp` 的实现一一对应。记号：`<>` 非终结符、
`::=` 产生式、`|` 或、`*` 零次或多次、`+` 一次或多次、`?` 可选、`{}` 分组、
`字面量` 终结符。

---

## 1. 词法

### 1.1 注释与空白

```
注释   ::= "//" 除换行外任意字符* | "/*" 任意字符* "*/"
空白   ::= 空格 | 制表符 | 换行 | 回车（任意数量）
```

`/* */` 注释**不嵌套**。

### 1.2 标识符与关键字

```
标识符  ::= [A-Za-z_][A-Za-z0-9_]*
```

**25 个关键字**（全部保留，不可作标识符）：

| 关键字 | 用途 |
|---|---|
| `fn` | system 方法声明（`fn update(ent e)`） |
| `return` `if` `else` `while` `do` `for` `break` `continue` | 语句 |
| `struct` `protocol` `impl` `component` `system` | 声明 |
| `extern` | 外部 C 函数声明 |
| `const` | 常量变量声明（解析但当前不强制只读） |
| `new` `delete` | 堆分配（`delete` 保留但无语义） |
| `null` `true` `false` | 字面量 |
| `ent` `void` `sizeof` | 类型 / 运算符 |
| `world` | 保留（ECS world 内部） |

### 1.3 字面量

```
整数字面量 ::= 十进制 [0-9]+ | 十六进制 0x[0-9a-fA-F]+ | 二进制 0b[01]+
浮点字面量 ::= [0-9]+ "." [0-9]+ （可带指数后缀）
字符串字面量 ::= '"' (可打印字符 | "\n" | "\t" | "\xHH")* '"'
字符字面量   ::= "'" 单字符 "'"
```

- **整数字面量默认无符号**：无后缀（`0u` 不合法）；按值域推断 `u32`/`u64`
- 负数写成 `-7`（解析器把「负号+整数字面量」标记为有符号 `i32`/`i64`）
- 字符串含 `\n`/`\t` 会导致汇编失败（数据段布局限制），用 `\xHH` 转义
- `null` 只能赋给指针；`true`/`false` 为 `bool`

### 1.4 运算符记号

```
算术   : + - * / %
位运算 : << >> & | ^ ~
比较   : < <= > >= == !=
逻辑   : && || !
赋值   : = += -= *= /= %= <<= >>= &= |= ^=
其他   : ? : ( ) [ ] { } , ; . -> & * ++ -- sizeof (T)expr
```

## 2. 类型

```
类型 ::= 基础类型 "*"*          // 指针后缀任意数量
基础类型 ::= "void" | "ent" | "u8" | "u16" | "u32" | "u64"
           | "i8" | "i16" | "i32" | "i64" | "f64" | "bool" | "char"
           | "ptr"             // 无类型指针（= void*）
           | 结构体名 | 协议名 | 组件名 | 泛型参数名
```

| 类型 | 宽度 | 说明 |
|---|---|---|
| `u8`/`i8` | 1B | 与 `bool`、`char` 同宽 |
| `u16`/`i16` | 2B | |
| `u32`/`i32` | 4B | `ent`（实体句柄）也是 u32 |
| `u64`/`i64` | 8B | |
| `f64` | 8B | 唯一浮点（`f32` 被拒绝） |
| `ptr` | 8B | 通用指针 |
| `T*` | 8B | 类型化指针 |

## 3. 顶层声明（程序）

```
程序     ::= { 顶层声明 }*
顶层声明 ::= 函数声明 | 结构体声明 | 协议声明 | impl 声明
           | 组件声明 | 系统声明 | extern 声明 | "#pragma unroll" N?
```

### 3.1 函数

```
函数声明 ::= 返回类型 函数名 泛型参数? "(" 参数列表 ")" "{" 语句* "}"
泛型参数 ::= "<" 泛型名 (":" 协议名)? { "," 泛型名 (":" 协议名)? } ">"
参数列表 ::= 空 | 参数 { "," 参数 }
参数     ::= "this"                                    // 协议/impl 方法专用
           | C风格: 类型 参数名
           | Swift风格: 参数名 ":" 类型
           | "ent" 参数名
```

```c
u64 fib(u64 n) { if (n < 2) return n; return fib(n - 1) + fib(n - 2); }
u32 add3(u32 a, u32 b, u32 c) { return a + b + c; }
void report(u32 v) { print(v); }
T max<T>(T a, T b) { ... }        // 泛型（T 可用协议约束 T: Comparable）
```

- 程序入口：`void main()`
- 函数必须先声明后调用（定义顺序无关，但调用点须已解析到声明）
- 函数前置声明（`retType name(...);` 无函数体）不支持——外部函数用 `extern`

### 3.2 结构体

```
结构体声明 ::= "struct" 名字 "{" { 类型 字段名 ";" }* "}" ";"
```

```c
struct Shape { u32 x; u32 y; u32 w; u32 h; }
```

### 3.3 协议（面向协议）

```
协议声明 ::= "protocol" 名字 "{" { 返回类型 方法名 "(" 参数列表 ")" (";" | "{" 语句* "}") }* "}" ";"
```

协议方法**必须**以 `this` 为第一个参数；`;` = 纯接口，`{...}` = 默认实现：

```c
protocol Shape {
    f64 area(this);
    u32 width(this) { return 10; }   // 默认实现
}
```

### 3.4 impl（实现协议）

```
impl声明 ::= "impl" 协议名 "for" 类型名 "{" { 返回类型 方法名 "(" 参数列表 ")" "{" 语句* "}" }* "}" ";"
```

```c
impl Shape for Square {
    f64 area(this) { return w * w; }
}
```

### 3.5 组件与系统（ECS）

```
组件声明 ::= "component" 名字 "{" { 类型 字段名 ";" }* "}" ";"
系统声明 ::= "system" 名字 (":" 组件名 { "," 组件名 })? "{" { "fn" "update" "(" "ent" 参数名 ")" "{" 语句* "}" }* "}" ";"
```

```c
component Position { f64 x; f64 y; }
system Physics : Position {
    fn update(ent e) { ... }
}
```

（当前版本 system 只支持单个 `fn update(ent e)`。）

### 3.6 extern（外部 C 函数）

```
extern声明 ::= "extern" 返回类型 函数名 "(" { 类型 (参数名)? { "," 类型 (参数名)? } } ")" ";"
```

```c
extern i32 tp_add(i32 a, i32 b);
extern void memcpy(ptr dst, ptr src, u64 n);
```

`malloc`/`free`/`memcpy`/`dlopen`/`dlsym` 由编译器**自动注册**（无需声明）。

## 4. 语句

```
语句     ::= 块 | if语句 | while语句 | do-while语句 | for语句
           | "break" ";" | "continue" ";" | "return" 表达式? ";"
           | "const"? 变量声明 | 表达式语句
块       ::= "{" { 语句 | "#pragma unroll" 数字? }* "}"
```

### 4.1 变量声明

```
变量声明 ::= 类型 变量名 数组维数? 初始化? ";"
数组维数 ::= "[" 常量整数 "]"
初始化  ::= "=" 表达式 | "=" "{" 表达式 { "," 表达式 } "}"   // 结构体按字段序
```

```c
u32 x = 5;
u64 big = 10000000000;
i32 neg = -7;
f64 f = 3.5;
ptr p = malloc(64);
u8 arr[16];
Shape s = { 10, 20, 30, 40 };
const u32 c = 100;
```

**歧义取舍**：`x * y;` 会被解析为指针变量声明（`x` 是类型名），与 C 的 typedef 消歧同理。

### 4.2 控制流

```c
if (条件) 语句 ("else" 语句)?
while (条件) 语句
do 语句 "while" (条件) ";"
for (初始化? ";" 条件? ";" 步进?) 语句
```

`for` 的初始化可以是变量声明（`for (u32 i = 0; ...)`）或表达式；
循环展开优化用 `#pragma unroll N`（放块内，作用于下一个 `for`）。

### 4.3 其它

```c
return;         // void
return 表达式;  // 按函数返回类型 coercion（字面量也必须匹配宽度）
break; continue;
print(表达式); printc(表达式);
```

## 5. 表达式（优先级从低到高）

```
表达式        ::= 赋值表达式
赋值表达式    ::= 三元表达式 (赋值运算符 赋值表达式)?
三元表达式    ::= 逻辑或 ("?" 表达式 ":" 三元表达式)?
逻辑或        ::= 逻辑与 { "||" 逻辑与 }
逻辑与        ::= 位或 { "&&" 位或 }
位或          ::= 位异或 { "|" 位异或 }
位异或        ::= 位与 { "^" 位与 }
位与          ::= 相等 { "&" 相等 }
相等          ::= 关系 { ("==" | "!=") 关系 }
关系          ::= 移位 { ("<" | "<=" | ">" | ">=") 移位 }
移位          ::= 加法 { ("<<" | ">>") 加法 }
加法          ::= 乘法 { ("+" | "-") 乘法 }
乘法          ::= 一元 { ("*" | "/" | "%") 一元 }
一元          ::= ("!" | "~" | "-" | "+" | "&" | "*" | "++" | "--") 一元
               | 后缀
后缀          ::= 基本 { ("(" 实参列表 ")" | "[" 表达式 "]"
                        | "." 成员名 | "->" 成员名 | "++" | "--"
                        | "<" 类型名 ">" "(" 实参列表 ")") }   // 泛型调用
基本          ::= 字面量 | 标识符 | "(" 表达式 ")" | "(" 类型 ")" 表达式
               | "new" 类型 "[" 表达式 "]" | "sizeof" "(" 类型或表达式 ")"
               | "true" | "false" | "null"
```

赋值运算符：`= += -= *= /= %= <<= >>= &= |= ^=`（右结合）。

```c
print(1 + 2 * 3);            // 7
i32 r = (u32)3.9;            // 强转
u64 b = bytecode_base();     // 内省
ptr q = &x;  i32 v = *q;     // 取址/解引用
Shape* sp = &s;  u32 w = sp->w;
u8 m = arr[3];
u32 id = get<Position>(e);   // 泛型调用（ECS）
```

**泛型调用消歧**：`名字 < 类型名 > (实参)` 视为泛型调用（否则 `<` 是小于号）。

## 6. 内建函数

| 名字 | 签名 | 说明 |
|---|---|---|
| `print` | 任意可打印类型 → void | 按类型分发（u32 一行、u64/i64/f64/bool/str 逐字符） |
| `printc` | (u8/char) → void | 输出单个字符 |
| `sqrt`/`log` | 数值 → f64 | 数学函数 |
| `getsystem` | → u64 | 低16位=平台、次16位=架构（OP_GET_SYSTEM） |
| `dload` | (字符串字面量) → ptr | `dlopen("lib/"+名, 2)`，动态链接默认根目录 `lib/` |
| `dl_reg` | (fnPtr, 签名串) → u32 | 运行时注册 C 函数（DL_REG） |
| `dl_call` | (idx, 签名串, 实参...) → 由签名定 | 按运行时索引调用（DL_CALL） |
| `malloc`/`free`/`memcpy` | 自动 extern | 堆与内存拷贝 |
| `dlopen`/`dlsym` | 自动 extern | libc 动态链接 |
| `bytecode_base`/`manager_addr` | → u64 | VM 内省 |
| `atomic_load/store/add/xchg_u32/u64` | (addr, v?) → 值 | 多线程原子操作 |

签名串格式：`返回类型(参数类型,...)`，类型名 `u8/i8/u16/i16/u32/i32/u64/i64/f32/f64/ptr/void`。

## 7. 已知语法限制与歧义

1. **整数字面量默认无符号**：`0 - 7` 按 u32 回绕为 `4294967289`；负数写 `-7` 或显式类型
2. **`x * y;` 歧义**：解析为指针变量声明（同 C typedef 消歧）
3. `f32` 类型被拒绝（请用 `f64`）
4. `char` 字面量是独立类型，不能与 u8 混算、不能参与算术
5. 字符串含 `\n`/`\t` 会导致汇编失败（用 `\xHH`）
6. 泛型仅单类型参数（`T`），无泛型结构体语法
7. `delete` 关键字保留但无语义；`world` 保留
8. dl_reg/dl_call 的签名串必须一致（编译期决定参数布局、运行期 VM 按已注册 cif 调用）
9. 函数前置声明不支持（外部函数用 `extern`）
10. dl_call 的签名必须是**字符串字面量**（编译期解析）
